# Analog-comms-ex

This repository contains a Codebase (MATLAB &amp; Python) for Analog Telecommunications programs.Each project is stored in its own subfolder with code and documentation.

## 📑 Table of Contents:

1. [Amplitude Modulation (AM) Simulation with GUI (Python)](./amp_modu)  
  This exercise involves the development of a Python program with a **Graphical User Interface (GUI)** designed to simulate the fundamental processes of Amplitude Modulation (AM) and Demodulation.
2. [Radar System with Servo and Processing](./projectultra/radar)  
   A servo-mounted ultrasonic sensor scans the area and visualizes the data in real time using Processing on a PC.
3. [An LED connected to D7 starts blinking at 0.5 Hz](./ledfreq)

# Analog-comms-ex

This repository contains a Codebase (MATLAB &amp; Python) for Analog Telecommunications programs.  
Each project is stored in its own subfolder with code and documentation.

## 📑 Table of Contents:

1. [Parking Assistance System](./projectultra/parkingproj)  
   Uses an ultrasonic sensor, buzzer, LEDs, and LCD display to detect distance and notify the driver about parking space availability.
2. [Radar System with Servo and Processing](./projectultra/radar)  
   A servo-mounted ultrasonic sensor scans the area and visualizes the data in real time using Processing on a PC.
3. [An LED connected to D7 starts blinking at 0.5 Hz](./ledfreq)
